🎯 WHAT IS THIS?
═══════════════════════════════════════════════════════════════════

A production-ready Gulp-based development environment that:

✅ Compiles SCSS to CSS automatically
✅ Removes unused CSS with PurgeCSS
✅ Minifies CSS for production
✅ Adds vendor prefixes for browser compatibility
✅ Provides live reload development server
✅ Generates 4 CSS versions (development & production)
✅ Uses latest Bootstrap 5.3.3
✅ Optimized for clean HTML/CSS/JS development

═══════════════════════════════════════════════════════════════════

Before:  Full CSS = 250KB
After:   Purged + Minified CSS = 40KB

FILE SIZE REDUCTION: 84%
PAGE LOAD IMPROVEMENT: 84% faster


🚀 QUICK START (2 MINUTES)
═══════════════════════════════════════════════════════════════════

💻 WHAT COMMANDS ARE AVAILABLE?
═══════════════════════════════════════════════════════════════════

npm start              → Start dev server (MOST USED)
npm run build          → Production build
npm run css            → Just compile SCSS
npm run css:purge      → Compile + purge + minify
npm run clean          → Delete generated CSS

gulp watch             → Development mode (default)
gulp build             → Production build
gulp css               → Compile SCSS only
gulp purge             → PurgeCSS only
gulp minify            → Minify CSS only


📁 WHAT FILES DO I GET?
═══════════════════════════════════════════════════════════════════

After running 'npm start', you get 4 CSS versions:

Development Files:
  src/css/full/style.css         ← Use during development
  src/css/full/style.css.map     ← For debugging

Production Files:
  src/css/full/style.min.css     ← Full Bootstrap minified
  src/css/style.css              ← Only used styles
  src/css/style.min.css          ← Purged + minified ⭐ BEST


🎨 WHICH CSS FILE SHOULD I USE?
═══════════════════════════════════════════════════════════════════

DEVELOPMENT (while coding):
<link rel="stylesheet" href="css/full/style.css">
✅ Has sourcemap for debugging
✅ Readable format
✅ All Bootstrap classes

PRODUCTION (when deploying):
<link rel="stylesheet" href="css/style.min.css">
✅ 84% smaller file
✅ Only used CSS
✅ Minified
✅ FASTEST page loads

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: npm install fails
→ Solution: npm cache clean --force, then retry

Problem: Port 3000 in use
→ Solution: Change port in gulpfile.js

Problem: CSS classes removed
→ Solution: Add to safelist in gulpfile.js

Problem: Sourcemaps not working
→ Solution: Use css/full/style.css (not purged version)

More help: See INSTALLATION.md
